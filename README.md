
# 🌐 Kişisel Portfolyo Web Sitesi

Fırat Üniversitesi Yazılım Mühendisliği bölümü **Web Tasarımı ve Programlama** dersi kapsamında geliştirilmiş, tam duyarlı (responsive) ve erişilebilir (accessible) kişisel portfolyo web projesi.

## 📝 Haftalık Gelişim Kayıtları (LAB Log)

### 🗓️ LAB-1: Temeller ve Ortam Kurulumu
* **Geliştirme Ortamı:** Proje altyapısı, versiyon kontrol sistemi (Git) ve mühendislik standartlarına uygun klasörleme (`src/styles`, `screenshots` vb.) hiyerarşisi oluşturuldu.
* **Versiyon Kontrolü:** Proje GitHub'a entegre edilerek geliştirme süreci branch (dal) mimarisiyle güvence altına alındı.

### ♿ LAB-2: Semantik Web & Kapsayıcı Tasarım
* **Semantik HTML5:** `<header>`, `<main>`, `<section>`, `<article>` gibi anlamsal etiketlerle SEO uyumlu iskelet oluşturuldu.
* **Erişilebilirlik (a11y):** ARIA etiketleri ve Skip Link (Ana içeriğe atla) entegrasyonu ile ekran okuyucu uyumluluğu ve en üst düzey erişim desteği sağlandı.
* **Doğrulama:** Klavye navigasyonuna uygun, kullanıcı deneyimini önleyen hataları minimize eden HTML5 tabanlı akıllı iletişim formu tasarlandı.

### 🎨 LAB-3: Responsive Dizayn & Tasarım Sistemi
* **Design Tokens:** Tüm tasarım dili (renk, font, boşluk) `tokens.css` içinde merkezi değişkenlere (`--var`) bağlandı.
* **Fluid Layout:** `clamp()` fonksiyonuyla ekran boyutuna göre otomatik ölçeklenen akıcı tipografi sistemi kuruldu.
* **Akıllı Izgara (Grid):** `auto-fit` mimarisiyle sıfır media-query yüküyle çalışan 3-kademeli (Mobil, Tablet, Masaüstü) responsive proje kartı düzeni oluşturuldu.
* **Belgelendirme:** Tasarım sırasında alınan kritik kararlar `CSS-KARARLARI.md` içinde teknik olarak raporlandı.
